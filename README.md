# Jenga Celestial Online — 4 jugadores

Sistema de salas online con código. Cada participante escribe únicamente su propio nombre y puede crear o unirse a una sala.

## Render
- Build: `npm install`
- Start: `npm start`
- Root Directory: vacío

## Flujo
1. Jugador 1 escribe su nombre y pulsa CREAR SALA.
2. Comparte el código de 6 caracteres.
3. Jugadores 2–4 escriben su propio nombre, colocan el código y pulsan UNIRSE.
4. Al llegar a 4 jugadores, el anfitrión inicia.
